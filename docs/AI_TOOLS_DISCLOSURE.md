# AI Tools and Development Disclosure

## 1. AI-Assisted Development Tools

The Continuity AI project was developed with assistance from the following AI tools:

- **ChatGPT:** Technical guidance, planning, debugging assistance, documentation and development support.
- **Claude:** Code review, reasoning and implementation assistance.
- **Gemini:** Technical research, problem-solving and development assistance.
- **Kilo Code:** AI-assisted coding and development workflow.
- **Continue:** AI-assisted development and coding support within the IDE.
- **Antigravity:** AI-assisted development, code generation and workflow support.

These tools were used as development assistants. The project implementation, integration, testing and submission preparation were carried out through the development workflow.

## 2. AI Components Within the Application

The application's AI-related functionality should be described separately from the AI tools used to develop it.

- Claim extraction and evidence processing.
- Retrieval-Augmented Generation (RAG)-related workflows, where implemented.
- Conflict and information-gap detection.
- FakeLLM test adapter for controlled and reproducible testing.

The FakeLLM adapter is used for testing. It should not be represented as a live external LLM integration.

## 3. Transparency and Verification

AI-assisted development does not replace software verification. The project was tested through frontend contract tests, backend tests and application workflow checks.

The team remains responsible for the implementation, testing, security, reliability and final submitted deliverables.

The submitted demonstration uses its configured demo environment. No personal third-party API credentials are intended to be included in the submission.
